# Excel Sales Dashboard

## Project Overview

This project analyzes sales data using Microsoft Excel and presents the results through an interactive dashboard.

## Tools Used

- Microsoft Excel
- Excel Formulas
- PivotTables
- Charts
- Data Cleaning
- Data Analysis

## Analysis Performed

- Sales analysis by region
- Product performance analysis
- Salesperson performance analysis
- Monthly sales trend analysis
- Identification of top-performing products
- KPI and dashboard creation
